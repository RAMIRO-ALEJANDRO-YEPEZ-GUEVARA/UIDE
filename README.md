2.Control del movimiento de la serpiente utilizando las flechas del teclado.
3.Generación aleatoria de alimentos dentro del tablero.
4.Incremento automatico del tamaño de la serpiente al consumir alimento.
5.Sistema de puntuación que registra los alimentos consumidos.
6.Detección de colisiones con los límites del escenario.
7.Detección de colisiones con el propio cuerpo de la serpiente.
8.Finalización automática de la partida cuando ocurre una colisión.
9.Pantalla de game over.
10.Reinicio del juego.
11.Actualización continua de la interfaz gráfica durante la ejecución del programa.

Introducción:

La programación constituye una de las competencias fundamentales en el desarrollo de software, ya que permite diseñar soluciones lógicas para resolver diferentes problemas mediante el uso de algoritmos y lenguajes de programación. Antes de implementar un sistema es necesario comprender el problema, analizar los requerimientos y diseñar una solución adecuada utilizando herramientas como diagramas de flujo, diagramas de arquitectura y diagramas de caso de uso.
En el presente proyecto se desarrolla una aplicación interactiva implementada en Python utilizando el entorno de desarrollo Visual Studio Code. el proyecto comprende diferentes etapas de desarrollo del software, desde el analisis del problema y el diseño de la solución hasta la implementación del programa y la realización de pruebas básicas.

Descripción del problema: 

El problema planteado consiste en desarrollar un videojuego interactivo en el que el usuario controle una serpiente dentro de un tablero de juego. Durante la ejecución del juego el sistema debe controlar continuamente el movimiento de la serpiente, verificar la aparición de nuevos alimentos y detectar posibles colisiones. Cuando una colisión ocurre la partida finaliza y el sistema debe informar al usuario el resultado obtenido.
Para resolver este problema fue necesario analizar los requerimientos funcionales del sistema, identificar las principales funcionalidades, diseñar los diagramas correspondientes y desarrollar una solución organizada mediante módulos que facilitan la comprensión, el mantenimiento y la reutilización de código.

Relación con los contenidos de la asignatura: 

El desarrollo del proyecto permitió aplicar de manera práctica los contenidos estudiados durante la asignatura, la capacidad para analizar problemas, diseñar soluciones lógicas y realizar pruebas para verificar el correcto funcionamiento del programa. Se emplearon estructuras de control como condicionales y ciclos para controlar movimientos, detectar colisiones y administrar la puntuación.

Explicación del sistema desarrollado: 

El sistema desarrollado corresponde a un videojuego de entretenimiento basado en el clasico juego de la serpiente. Al iniciar la aplicación se crea una ventana gráfica donde el jugador controla una serpiente utilizando las teclas de dirección del teclado. Durante la partida aparecen alimentos en posiciones aleatorias del escenario. Cada vez que la serpiente consume un alimento, aumenta su tamaño y se incrementa la puntuación del jugador. El sistema supervisa continuamente el movimiento de la serpiente para detectar colisiones con los bordes de la pantalla o con su propio cuerpo. Cuando ocurre una colisión el juego finaliza mostrando un mensaje de "Game over" y ofrece la posibilidad de reiniciar la partida. El desarrollo del proyecto se realizó utilizando una arquitectura modular, separando las resposabilidades del programa en diferentes archivos para facilitar el mantenimiento, la organización, y la reutilización del código.
